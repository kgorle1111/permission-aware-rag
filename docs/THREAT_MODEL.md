# Threat model

Every **controlled** or **accepted** row cites the check that pins it. `app/test_ledgers.py`
fails if a cited file or anchor disappears. **open** rows are known gaps, listed
so nobody mistakes silence for safety.

| Id | Threat | Control | Test | Status |
|---|---|---|---|---|
| T01 | Forbidden doc returned for an exact-content query | Pre-filter before ranking (in-memory); RLS policy (pgvector) | `app/test_permission_rag.py` "THE leak test"; `app/eval_scale.py` "must-not trial" | controlled |
| T02 | Hidden doc shifts visible scores via corpus statistics | Visible-set BM25 stats; pgvector scores are per-row | `app/test_permission_rag.py` "S1: IDF side channel"; `app/run_evals.py` "def isolation_gate" | controlled |
| T03 | Bare-string ACL iterated into characters (`"*"` inside → public) | `normalize_acl` rejects str/bytes | `app/test_permission_rag.py` "a bare str must not be iterated" | controlled |
| T04 | Malformed ACL entry (empty, comma, trailing newline) | `fullmatch` on a strict entry pattern | `app/test_permission_rag.py` "group:hr\n" | controlled |
| T05 | Comma in a user id/group forges an extra principal in the RLS GUC | `principals()` rejects commas and empties | `app/test_pgvector.py` "def test_acl_and_principal_boundary" | controlled |
| T06 | Result cache shared across principals | No cache exists; the isolation gate catches a principal-less cache | `app/mutants.py` "class SharedCache" | controlled |
| T07 | Prefix or wildcard group matching (`group:hr` reads `group:hr-admin`) | Exact set membership in `can_read`; trap ACLs in both evals | `app/mutants.py` "class GroupPrefix"; `app/run_evals.py` "group:underwriting-admin" | controlled |
| T08 | Cross-user audit query read | New records contain ids/counts and a redacted query placeholder; audit views redact legacy query text for every caller and omit chain hashes | `app/test_security.py` "def test_audit_query_redaction" | controlled |
| T09 | Document text or id closes the prompt's data boundary | Escape text and ids before framing; system prompt says data-not-instructions, and a fixed reminder after the last document restates it (sandwich defense). Semantic prompt injection remains possible | `app/test_security.py` "def test_document_breakout" | controlled (structural breakout only) |
| T10 | Model cites a doc it wasn't given | Post-hoc check surfaces unknown bracketed ids, including slashes, colons and spaces; this does not verify claim support | `app/test_security.py` "def test_citations_with_real_document_ids" | controlled |
| T11 | Hidden-document count reveals that forbidden docs exist | `SHOW_DENIED=0` removes it outside the demo | `app/test_http.py` "SHOW_DENIED off" | accepted (on in demo by design) |
| T12 | Edit or truncate the newest audit entry | JSONL chain checked against a separate local head checkpoint; pgvector checks stored line hashes. Rewriting both log and checkpoint needs an independently retained head; pgvector tail deletion remains unanchored | `app/test_security.py` "def test_audit_tail_tamper"; `app/test_security.py` "def test_audit_checkpoint_is_required"; `app/test_pgvector.py` "def test_newest_audit_entry_tamper" | controlled for edits and JSONL-only truncation; broader storage attacker accepted |
| T13 | SQL on the app connection grants itself ingest: forges `rag.mode` or writes chunks | Ingest is a separate DB role on its own connection; the app role has SELECT-only on chunks and no membership in the ingest role; setup REVOKEs legacy write grants | `app/test_pgvector.py` "def test_app_role_cannot_ingest_or_widen_visibility" | controlled |
| T14 | Signed JWT whose claims aren't valid principals (comma in a group forges an RLS principal; a bare-string `groups` iterates into characters) | `user_from_jwt` accepts only a non-empty `sub` and a list of non-empty group names without commas or whitespace; anything else is a 401 | `app/test_security.py` "def test_jwt_claims_must_be_valid_principals" | controlled |
| T15 | Aggregation: combining permitted docs to infer a forbidden fact | Out of scope for retrieval ACLs; human review of drafts | none | open |
| T16 | Formula execution when opening an audit CSV | Prefix dangerous cells with an apostrophe at export; source audit stays unchanged | `app/test_security.py` "def test_audit_csv_formula_injection" | controlled |
| T17 | Non-object JSON or invalid field types cause a request crash | Explicit body and query type checks; retrieval failures return 503 without results | `app/test_security.py` "def test_non_object_body_is_400"; `app/test_security.py` "def test_invalid_field_types_are_400"; `app/test_security.py` "def test_retrieval_error_is_503" | controlled |
| T18 | SQL on the app connection forges principals to widen what it can read | Principals reach RLS only as an HMAC-SHA256-signed, 60-second token verified inside Postgres by a SECURITY DEFINER function, with a key in a table neither app role can read; a raw `rag.principals` setting is ignored | `app/test_pgvector.py` "def test_forged_principals_cannot_widen_visibility" | controlled |
| T19 | SQL on the app connection runs unaudited reads, appends forged audit entries, or reads audit metadata | The app role has no SELECT on chunks and no INSERT on audit; every read goes through `rag_search`, a SECURITY DEFINER function owned by a NOLOGIN, non-BYPASSRLS role, which verifies the signed token, applies RLS and writes the hash-chained audit row server-side with exactly the ids it returned. Reading audit metadata (user ids, returned chunk ids, no query text) remains: the app needs SELECT on audit for its `/audit` view | `app/test_pgvector.py` "def test_app_role_can_only_search_through_the_audited_function" | controlled for unaudited reads and forged entries; metadata reads accepted |
| T25 | An LLM-written SQL statement (hostile model, or a prompt-injected question) reads rows or tables the caller may not, writes, escapes its role, stalls the audit chain, or runs unaudited; aggregates (`count`, `sum`, `min`) over metadata include hidden rows (the T15 shape, for structured data) | The statement runs inside `rag_sql_run`, which verifies the signed token (T18), executes `rag_sql_exec` as `rag_sql` (NOLOGIN, non-BYPASSRLS, not the table owner, no SET ROLE to undo), and writes the hash-chained audit row itself with hashes and status, never text (T19 pattern). `rag_sql` can read only the non-ACL columns of `doc_meta`, whose RLS policy uses the same signed principals; the statement opens as a cursor (exactly one query), under `transaction_read_only`, a 2 s `statement_timeout` and a 100-row cap; session advisory locks are released. The app's pre-check is defence in depth: the adversarial suite bypasses it | `app/test_text_to_sql.py` "def test_hostile_sql_errors_or_returns_only_visible_rows"; `app/test_text_to_sql.py` "def test_aggregates_count_only_visible_rows"; `app/test_text_to_sql.py` "def test_metamorphic_hidden_rows_never_change_a_low_privilege_result"; `app/test_text_to_sql.py` "def test_every_attempt_is_audited_by_the_database_without_text" | controlled for the 40 hostile statements and the aggregates tested; residuals accepted: `pg_class.reltuples`/`pg_stat_*` expose the table's total row estimate to any role (B15), and `doc_meta` visibility is document-level only (B14) |
| T26 | PDF-derived text (body, table sentences, OCR output) escapes the document ACL or PII redaction | Extraction only produces a corpus document; chunking stamps the document ACL on every chunk and redacts there, so extracted text takes the same path as any other text. A missing OCR engine raises instead of silently dropping a page | `platform/tests/test_pdf_ingest.py` "def test_every_extracted_chunk_inherits_the_document_acl_and_outsiders_get_nothing"; `platform/tests/test_pdf_ingest.py` "def test_pii_redaction_still_applies_to_extracted_pdf_text"; `platform/tests/test_pdf_ingest.py` "def test_missing_ocr_engine_fails_loudly_not_silently" | controlled |
